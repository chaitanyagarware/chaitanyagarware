## Featured project

### AWS Cloud Security Scanner

A local-first AWS security analysis tool for reviewing IAM risk, CloudTrail activity, GuardDuty findings, and Access Analyzer results.

Repository: [aws-cloud-security-scanner](https://github.com/chaitanyagarware/aws-cloud-security-scanner)

It focuses on:

- IAM policy and trust policy review
- CloudTrail behavior analysis
- GuardDuty finding triage
- Access Analyzer finding ingestion
- MITRE ATT&CK mapping
- SARIF, ASFF, and OCSF-style outputs
- Suppression rules and severity overrides
- Finding state and deduplication
- Least-privilege review workflows
